PAINEL PEDAGÓGICO — IDEALIZA
============================

Estrutura dos arquivos:
- index.html   → estrutura da página (HTML)
- style.css    → toda a estilização visual (CSS)
- script.js    → toda a lógica/funcionamento (JavaScript)
- logo.png     → logotipo da Idealiza

Para usar: basta abrir o index.html em qualquer navegador. Não precisa de
servidor nem instalação — os dados dos alunos e das contas já estão
embutidos dentro do próprio index.html (nas tags <script type="application/json">).

IMPORTANTE — sobre o botão "Salvar alterações":
O botão de salvar foi feito para funcionar dentro do site hospedado pela
Claude (o link que você já tem). Fora de lá — abrindo este ZIP direto no
navegador ou hospedando em outro serviço (GitHub Pages, Hostinger, etc.) —
o botão não vai conseguir gravar as alterações automaticamente, porque
isso depende de um recurso específico da plataforma da Claude.

Se quiser hospedar esse site em outro lugar E manter a edição funcionando
(qualquer pessoa alterando o status dos alunos e isso salvando de verdade
para todo mundo ver depois), você vai precisar de um back-end/banco de
dados próprio. Se for esse o caso, me avise que ajudo a montar isso.
